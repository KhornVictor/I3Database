# Mini Project: Relational Database

This repository contains the materials for a relational database mini project. It is intended to document the project brief, the database work, and the final report for the assignment.

## Project Overview

The goal of this project is to design, build, and document a relational database solution for a chosen scenario. The repository is organized to keep the assignment brief, database-related assets, and final report in one place.
